Privacy Policy — shortstobench

Last updated: 2026-10-15

shortstobench is a private tool used only by its owner on the owner's own computer.

Data accessed

When the owner signs in with Google, the tool receives an OAuth token for the YouTube Data API (https://www.googleapis.com/auth/youtube.force-ssl). It uses that token only to upload the owner's videos, set their title, description, tags and scheduled publish time, and read back the uploaded video's details.

Storage and sharing

  • The token is stored only on the owner's computer. It is not sent to any server other than Google's.
  • No data is sold, shared with third parties, or used for advertising.
  • No data from any other Google user is collected.

Google API Services User Data Policy

shortstobench's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
